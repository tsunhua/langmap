## 對照集詳情頁 (detail.html)
**問題**:對照集(映射 + 讚踩 + 折疊 + 1-3 跳)該長怎樣?
**Variants**:A 稠密表格 / B 徑向圖譜 / C 卡片動態。
**勝出**:**B 徑向圖譜**。
**理由**:新模型的第一性實體是「語義圖譜」;B 把「詞句為節點、映射為邊、評分為邊粗細」直接視覺化,讓用戶一眼看到站的本質。A 太像舊字典、C 把圖譜拍平成社群牆,兩者都淡化了「圖」這個核心。
**狀態**:detail.html 已清理為 B-only;A/C 與 switcher 移除。
