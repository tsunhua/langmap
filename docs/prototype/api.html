STEP 02
初始化客户端
在控制台获取 API Key，每月 50k 次免费额度，超量按量计费。
import LangMap from "langmap-api" const lm = new LangMap({ key: "lm_live_xxxxxxxxxxxx" })
STEP 03
查询词句翻译
按词条 slug 或自由文本查询；响应含地区、来源质量与坐标。
const res = await lm.lookup({ text: "Have you eaten yet?", lang: "en", group: "greeting.meal" }) // → { expressions: [...], total: 12 }
