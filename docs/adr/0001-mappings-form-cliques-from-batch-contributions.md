# 跨語言映射以完全圖成形,批次貢獻視為對所有 pair 的集體斷言

廢掉 meaning/組之後,跨語言連結改為 pairwise「映射」。當貢獻者一次提交 N 個「表達同一件事」的詞句(批次貢獻)時,系統在兩兩之間建立直接映射(完全圖,共 N(N−1)/2 條),每條都是獨立可讚可踩的直接映射。

選完全圖而非星型或鏈型的理由:站在任何一個詞句看,1 跳的對照集就是完整的多語對照,不必依賴某個被選中的「錨」;而且完全圖讓每一 pair 都能被獨立讚踩(例:{吃了吗, Have you eaten, 食饱未} 可單獨踩「吃了吗 ↔ 食饱未」而不影響另外兩條),這是星型做不到的細粒度。

考慮過但否決的方案:星型(只有從錨點看才豐富)、鏈型(處處稀疏)、不自動建邊(貢獻負擔過重、新詞句初始無對照集)。代價:邊數隨 N² 成長,多數直接映射初始評分為 0、從未被單獨審視,品質靠後續讚踩浮現。
