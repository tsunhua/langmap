# 重新想像的站體結構:動態首頁、對照集獨立頁、地圖降為透鏡、收藏砍除、手冊簡化

廢掉 meaning/組、改用 pairwise 映射(見 ADR-0001、`CONTEXT.md`)之後,站體結構跟著重新想像,以「圖譜 + 社群訊號」為核心。本則記錄幾個互相關聯、難逆且會讓人疑惑的結構決定。

**決定:**

1. **首頁 = 動態 feed**(熱門 + 最新,單位是映射/詞句),取代原本的地圖首頁。新價值(讚/踩/折疊)都發生在圖譜層,地圖當首頁會把新價值埋進二級頁。
2. **對照集 = 獨立頁面**,每個詞句一個 URL、可分享;SPA 式流暢漫遊為實作層,不影響 IA。參考/探索站的可分享 URL 是命脈。
3. **地圖從首頁降為「透鏡」**:從詳情頁以「看此詞句在地圖上的分布」入口,不再是預設落點、不進導覽。新模型第一性是語義圖譜(非地理);但語言天生有地理、且 LangMap 品牌含「Map」,故保留為輔助視角而非砍除。
4. **收藏集合整個砍掉**:無收藏實體、連「已收藏」旗標都不要;策展只剩手冊。收藏與簡化後的手冊資料形狀重複,且與核心動線正交。
5. **手冊簡化**:去掉 Markdown 與正文,只剩「章節標題 + 有序詞句」。手冊原靠嵌入詞句組做多語渲染,組沒了、且多義漂移使自動渲染不可靠;改為作者直接挑詞句,放棄自動多語、換來確定性與極簡。
6. **頂部導覽**:手冊、語言;header 上「貢獻」CTA、全域搜索、UI 語言切換;地圖=透鏡、API=footer。

整體方向:把站從「以地理地圖為首的詞句目錄」推向「以語義圖譜 + 社群動態為首的探索工具」,並砍掉正交或沉重的功能(收藏、手冊正文)以換取聚焦。
